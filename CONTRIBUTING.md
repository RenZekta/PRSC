# Contributing

This repository is an early research proposal. Contributions should preserve the distinction between established prior results, architectural hypotheses, and measured findings.

- Cite primary sources for factual claims.
- Do not add performance numbers without reproducible experiments.
- Include exact model, tokenizer, encoder, cache-format, and corpus versions.
- Add failure cases, not only successful demonstrations.
- Treat cache compatibility and provenance as correctness requirements.
- Keep schema changes backward-compatible where practical and update the example and tests.

Before proposing a novelty claim, review recent preprints and concurrent work. PRSC's current literature positioning is selective rather than exhaustive.
